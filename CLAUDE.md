# EngLift — нотатки для агента

Цей файл — памʼять між сесіями. **Прочитай його на початку роботи, а після кожної завершеної задачі допиши запис у «Журнал змін» нижче** (найновіші зверху): що змінено, де, чому, і що лишилося відкритим. Повний опис функцій — у [english-app/README.md](english-app/README.md), тут лише те, що потрібно для роботи з кодом.

## Що це

Офлайн-PWA для вивчення англійської українською (автор — Руслан, спілкується українською; інтерфейс, коментарі в коді й повідомлення комітів — українською). Статичний сайт без збірки й фреймворків: vanilla JS (IIFE-модулі, `window.FL*`), публікується на GitHub Pages з `english-app/` через `.github/workflows/deploy.yml` (push у `main` → тести → деплой). Тобто **push у main = реліз**, комітити й пушити лише на прохання користувача.

## Структура (головне)

- `english-app/js/core.js` — `window.FLCore`: сховище прогресу (`store`, `save()` у localStorage), XP, утиліти, озвучення, ліниве завантаження скриптів.
- `english-app/js/lexis.js` — `window.FLLexis`: словник (браузер слів, картки, тренажери, Parts). Дані словника — `js/lexis/*-data.js`, вантажаться ліниво.
- `english-app/js/wod.js` + `js/lexis/wod/verbs-NN.js` — Word on Demand; джерело даних — `tools/wod/` (див. `tools/wod/SPEC.md`).
- `tools/examples/` — **джерело прикладів дієслів, прикметників та іменників** (`ex`/`exUk`/`ex2`): `out/<verbs|adjs|nouns>/*.json` → `node tools/examples/apply.js <pos>` пише в `verbs-data.js` / `verbs-phrasal-data.js` / `verbs-merge.js`, `adjs-data.js` / `adjs-prep-data.js` або `nouns-data.js`. Правити приклади цих частин мови лише в `out/` (інакше наступний `apply.js` затре правку). Вимоги — `SPEC.md`, перевірка — `validate.js <pos>`. Нова частина мови — додати її в `POS` у `common.js` і гілку запису в `apply.js`.
- `tools/oxford/` — **нові слова з Oxford 3000/5000** (3006 записів, `_id` від 10000): джерело — `out/<pos>/*.json`, `node tools/oxford/build.js` збирає `english-app/js/lexis/<pos>-oxford-data.js` (не редагувати вручну) і перераховує `meta.js`. Нові категорії — `categories.json` (додаються перед «18+», лише ті, де є слова). Реєстр сталих `_id` — `ids.json` (не видаляти, інакше зсунеться прогрес Word on Demand). Приклади цих слів теж живуть тут, а не в `tools/examples`.
- `english-app/js/practice.js` + `js/practice/<id>-data.js` — розділ «Практика» (пакети тем, реєстр `PACKS`).
- `english-app/js/phrases.js`, `sound.js`, `reader.js`, `diary.js`, `placement.js`, `search.js` — інші розділи.
- `tests/` — jsdom-тести, кожен набір — окремий файл, список у `tests/run-all.js`.
- `uploads/` — у `.gitignore`, вихідні матеріали; не чіпати.

## Обовʼязкові кроки при змінах

1. **Тести:** `cd tests && npm test` (≈2 хв). Новий набір тестів — додати в масив `TESTS` у `tests/run-all.js`.
2. **Service worker:** при будь-якій зміні файлів застосунку підняти версію `CACHE` в `english-app/sw.js` (інакше встановлений PWA не оновиться); новий файл — додати в `APP_SHELL`.
3. **Пошук:** якщо змінились слова, фрази, теми чи сторінки — `node tools/build-search-index.js`.
4. **README:** оновити опис і лічильники в `english-app/README.md` (таблиця розділів, кількість наборів тестів, структура файлів).
5. Цей файл — запис у журнал.

## Корисні факти

- Слово словника: `{ en, uk, ctx, uCtx, ipa, lvl, cats: [...], adult }`; `lvl` — A1…C2. Ключ картки — `cardKey(w)` = `en|ctx|uk`.
- Категорії/підкатегорії: `P.cats` / `P.subs` (у підкатегорії є `parent`); `special` — службові хаби (delex), без Parts.
- Режим 18+ (`adult`) фільтрується через `wVisible` / `catVisible`.
