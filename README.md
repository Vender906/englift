# EngLift

Офлайн-PWA для вивчення англійської: граматика, словник на 8 700+ слів, фрази й конструкції, вимова, читання, щоденник.

- [`english-app/`](english-app/) — сам застосунок (статичний сайт, саме його публікує GitHub Pages)
- [`tests/`](tests/) — автотести (jsdom), запускаються перед кожним деплоєм
- [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) — тести → збірка → GitHub Pages

Детальний опис, запуск локально й публікація — у [english-app/README.md](english-app/README.md).
