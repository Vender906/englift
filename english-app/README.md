# EngLift — PWA для вивчення англійської 🚀

Сучасний офлайн-застосунок для вивчення англійської мови: граматика з теорією, словник із тренажерами, диктанти та змішаний «Виклик».

**Теми оформлення:** 25 тем у галереї (кнопка 🌙 у верхньому куті або ⚙️ Налаштування): **12 динамічних** з анімованим фоном — Північне сяйво, Космос, Синтвейв, Матриця, Зимова ніч, Глибина, Світлячки, Лава-лампа, Дощ, Хамелеон, Весна, Сонячні зайчики — і **13 статичних** (Неон, Океан, Ліс, Захід сонця, Кава, Дракула, Графіт, Висока контрастність, Світла, Сакура, Пісок, М’ята, Небо). Анімації можна вимкнути; якщо в системі ввімкнено «зменшити рух», вони вимкнені за замовчуванням.

**✨ Світлові ефекти:** ⚙️ Налаштування → «Світлові ефекти» (або кнопка «✨ Ефекти» в галереї тем): підсвітка карток, сяйво при наведенні, прожектор за курсором, неоновий контур, світло за курсором на фоні, відблиск на кнопках, неонові заголовки, іскри при кліку. Кожен вмикається окремо, є три рівні інтенсивності та швидкі пресети.

**💾 Резервна копія:** ⚙️ Налаштування → «📤 Експорт» зберігає весь прогрес (XP, серія, граматика, слова, тема, читання, щоденник, тест рівня) в один .json; «📥 Імпорт» показує, що у файлі, і після підтвердження відновлює дані.

**Гейміфікація:** XP, рівні з назвами (Новачок → Легенда), серія днів 🔥, 6 досягнень, конфеті 🎊 — усе зберігається в `localStorage`.

**Тренажери:** тест із варіантами, введення відповіді, збирання речення зі слів, флеш-картки «Знаю / Не знаю» з повторенням невідомих, словникові тренажери на введення (переклад в обидва боки, форми дієслів, слово за контекстом, мікс), диктанти з порівнянням слів.

## PWA

- `manifest.json` — встановлення на телефон/комп'ютер як окремий застосунок
- `sw.js` — service worker: повна робота **офлайн** після першого відвідування
- Іконки 192/512 + maskable

## Як запустити локально

```bash
cd english-app
python3 -m http.server 8000
# → http://localhost:8000
```

## Публікація на GitHub Pages

Репозиторій уже підготовлений: у корені лежить `.github/workflows/deploy.yml`. На кожен push у гілку `main` він:

1. проганяє всі тести (`tests/`) — якщо щось зламано, сайт **не** оновиться;
2. збирає сайт із папки `english-app/` (без вихідника іконки `icons/icon_src.png`);
3. додає до версії кешу в `sw.js` короткий хеш коміту — встановлений PWA сам підтягне оновлення;
4. публікує результат на GitHub Pages.

**Перший запуск (один раз):**

```bash
cd 22.25                      # корінь проєкту: english-app/, tests/, .github/
git init -b main
git add .
git commit -m "EngLift"
git remote add origin https://github.com/<логін>/<репозиторій>.git
git push -u origin main
```

Далі на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Після зеленого запуску у вкладці **Actions** сайт буде за адресою `https://<логін>.github.io/<репозиторій>/`. Відкрийте її в Chrome / Edge / Safari → «Встановити застосунок» (на iPhone: «Поділитися → На початковий екран»).

**Оновлення:** просто `git add . && git commit -m "…" && git push`. Уже встановлений застосунок отримає нову версію після наступного відкриття (ще одне перезавантаження — і вона активна).

Нюанси:
- усі шляхи відносні, тож сайт працює і з підпапки `/<репозиторій>/`, і з власного домену;
- GitHub Pages розрізняє регістр імен файлів (на відміну від Windows) — перейменовуючи файли, змінюйте й посилання;
- сайт на GitHub Pages **публічний**: будь-хто з посиланням бачить увесь вміст, зокрема дані режиму 18+ і тексти книг;
- перше відкриття завантажує ~11 МБ для повного офлайну (словники й книги), далі все працює без мережі.

Застосунок статичний, тож підійде й будь-який інший хостинг із HTTPS (Netlify Drop, Cloudflare Pages, Vercel) — достатньо завантажити папку `english-app`.

> Прогрес зберігається в `localStorage` під ключем `fluentlab_v2`. Прогрес читання — під тими самими ключами, що й в оригінальному `reader.html` (`reader_progress`, `reader_done`, …), тож він переноситься. Так само й записи щоденника (`diary_entries_v1`, чернетка, ціль) — під ключами оригінального `english-diary-studio.html`.
>
> 🔞 **Режим 18+** — прихований, як в оригінальних тренажерах (~350 слів). Введи `18+` у пошуку браузера слів, щоб увімкнути; введи `18+` ще раз, щоб вимкнути (`unlock18`/`lock18` — явні варіанти).
>
> 🧭 Навігація: коли заходиш у розділ словника з бічної панелі, браузер завжди відкривається на хабі категорій.
